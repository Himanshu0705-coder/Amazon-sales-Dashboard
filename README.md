# 📊 Amazon Sales Dashboard — Power BI

An interactive **Amazon Sales Analytics Dashboard** built using **Microsoft Power BI** to analyze sales performance, product categories, order trends, and key business metrics.

The project demonstrates the complete analytics workflow — from **data preparation and transformation in Excel** to **data visualization and dashboard development in Power BI**.

---

## 🚀 Project Overview

The objective of this project is to transform raw Amazon sales data into an interactive business intelligence dashboard that helps users understand:

* Overall sales performance
* Product/category performance
* Sales trends over time
* Order volume
* Business KPIs
* Performance patterns and trends

The dashboard provides an easy-to-understand visual representation of the data, allowing users to explore the information through interactive Power BI visuals and filters.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Analyze Amazon sales data to identify important business trends.
* Build meaningful **Key Performance Indicators (KPIs)**.
* Analyze sales performance across different categories.
* Identify high-performing and low-performing products/categories.
* Understand sales trends over time.
* Create an interactive and user-friendly Power BI dashboard.
* Convert raw data into actionable business insights.
